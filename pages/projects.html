工坊

可观察、可复现、可回放的研究展示。

Interactive simulation

Agent Town / 小城应急局

一个用像素城市直观展示 Multi-agent 协作机制的交互模拟器。它把抽象的编排方式放进同一条可观察、可复现、可回放的应急处置轨迹中，让你看到消息如何流动、任务如何拆解，以及不同 Agent 如何汇合结果。

五种协作形式
  • Group Chat多角色轮流讨论，共享上下文并形成共识。
  • Supervisor中心节点拆解目标、委派子任务并统一收束。
  • Event BusAgent 通过事件发布与订阅实现松耦合协作。
  • DAG按依赖关系并行执行任务，在关键节点汇合结果。
  • Handoff把结构化上下文与任务所有权一起移交，并由接收方确认接管。

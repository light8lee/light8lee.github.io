# Qwen 用户记忆失败：从猜测走向定位

8 种插件在原增益的新会话自然回答中命中 0/96；放大到16倍后命中 0/96。KV/kNN 的原文存储、读取门控和强制读出另有独立测量，不能用一个原因概括所有失败。

本轮直接观察：

- 逐token最近邻用原始隐藏状态、32维投影、128维投影时，原写入前缀分别命中 12/12、12/12、12/12。移除旧历史但保留相同 user 前缀后，三组均为 1/12；assistant 前缀三组均为 0/12。因此，本组局部地址信息可以保留在投影中；仅上下文变化就足以使读出明显变差，尚未形成可靠的问答寻址关系。原隐藏状态/32维/128维的新问题自然回答分别为 0/12、0/12、1/12；单条命中不能支持可靠召回。
- 关闭余弦阈值使 KV 正确口令出现 2/12，但 4/12 题出现其他概念的口令；kNN 提升至 4/12，仅关闭词面过滤仍为 0/12。放宽门控有局部帮助，仍不能解决候选选错、复制 user 整段内容及回答格式问题。
- 残差两种方法在原写入前缀的Δℓ绝对值均小于0.001，当前更新没有表现出可用的口令读出。普通 Hebbian 与 EMA 的对应Δℓ为 -18.622、-19.248，正确token概率明显降低；Balanced Hebbian 为 +1.581，局部概率提高但自由生成仍为0/12。同一前三个案例，Balanced的原前缀Δℓ从单条的+4.030，降至6条的+2.638、12条的+1.966；追加更新确有退化，但单条仍不能完整续写，故容量不是全部解释。不同词表变体同时改变了规则、秩和增益，不能把变体差异归因于一个参数。

## 角色和实验边界

原写入前缀保留旧会话，是阳性诊断；新 user 前缀只含一条未完成说明；assistant 前缀只预填“启动口令是”；自然回答只给新问题。所有自由生成输入都在完整口令开始前截断。原起点回放和强制复制都属于 user 原文复现，不算 assistant 自主语义回答。

复用真实澄清对话和更正前的12概念快照；主干冻结，无反向传播，没有人工 assistant 更新目标。新单概念条件按概念重置，只写两条 user 正文，写与读为不同 OS 进程。

## 正确 token 概率：成功与局部变化分开

ℓ = (1/L) Σ log p(v_t | x, v_<t, M)。x是测试前缀，M是只读快照，v是完整口令的token序列，L是长度。评分时只提供前面正确的token，不更新参数。自由生成仍从不含口令的x开始。

Δℓ = ℓ(原增益) − ℓ(零增益)。正值意味着正确token的条件概率提高；不是自由生成成功，也不是概率百分比。

## 特征是否保留了可读信息

| 逐 token 最近邻的地址 | 原写入前缀 | 新 user 前缀 | assistant 前缀 | 新问题自然回答 |
| --- | --- | --- | --- | --- |
| 原始隐藏状态 | 12/12 | 1/12 | 0/12 | 0/12 |
| 32维随机投影 | 12/12 | 1/12 | 0/12 | 0/12 |
| 128维随机投影 | 12/12 | 1/12 | 0/12 | 1/12 |

此处把序列起点路由替换为逐 token 最近邻：原始隐藏状态与固定32/128维投影各测一组，值全部来自已保存的 user token。没有用答案选择条目。原前缀能成功，才说明该地址特征可以支持局部读取；新会话失败则说明局部读取与跨角色回答还有差距。它是查找参考，不算原8种方法的成绩。

## 结论应当分层

KV/kNN 可用原文清点、原地址回放、真实门控消融和强制读出定位存储、候选过滤与跨角色地址。残差/词表方案需要结合原前缀概率和单概念对照判断：如果单概念也不能续写，就不能把失败全归于多概念容量；如果正确token概率有改善但自由生成失败，也不能说完全没有写入作用。

本轮没有训练过的控制器对照，因此“缺少学过读写关系的控制器”仍是机制假设。单概念仅覆盖前三个案例；有限增益网格、零完整口令命中和平均概率变化，都不能证明全部信息已丢失，也不能否定所有无反向传播记忆方案。

同一 user 前缀对照只改变旧历史；assistant 条件同时改变问题形式、角色和上下文，不能将后者的差异单独归因于角色。

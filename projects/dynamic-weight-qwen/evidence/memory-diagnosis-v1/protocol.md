# 用户对话记忆失败：诊断实验协议

本轮复用 user-dialogue-v1 的真实澄清对话、12 个随机口令、8 种插件和种子 71。源记录及快权重文件不覆盖；结果存入独立目录。此文件记录测量设计，不宣称事前注册。

| 假设 | 干预或测量 | 支持该解释的证据 | 不能据此证明什么 |
|---|---|---|---|
| user 写入地址与 assistant 读取地址不匹配 | 原写入上下文的 user 前缀、新会话的同一句 user 前缀、新问题加通用 assistant 前缀、新问题自然回答 | 原地址能读，新问题不能；地址相似度或门控明显变化 | 原上下文续写不是跨会话理解 |
| 信息未完整存储，或不同内容发生干扰 | KV/kNN 源 token 清点；6→12 个概念；3 个独立重置的单概念存储 | 原文缺失；或同一案例在单概念有效、多概念失效 | 三个案例不代表完整容量曲线；增量写入同时有遗忘和干扰 |
| 找到了正确条目仍无法读取 | 从快权重快照中定位完整 user 原文，强制复制其实际存储的 token | 强制读仍失败才支持值/读出通路损坏；强制读成功排除这类故障 | 强制复制绕过地址及门控，不测语义理解；不能部署时使用答案索引 |
| 冻结模型不会使用 user 提供的内容 | 正确原始 user 文本、错误概念原文、无原文三组输入；插件增益置零 | 正确原文有效，错误或缺席无效，表明本组任务可由冻结模型完成 | 外部原文输入的成功不属于快权重成功 |
| 只是读取增益不够大 | 同一快照，增益乘数 0、1、4、16；问答、assistant 前缀续写和4个通用问题 | 增益增加使正确口令读出，才支持单纯强度不足 | 有限网格失败不能排除全部参数；输出变化不是通用能力准确率 |
| 随机投影没有学会适配读取任务 | 对比写入/读取位置的主干隐藏状态和投影编码相似度；检查局部目标概率与自由生成 | 地址和输出语义不一致只能提供间接支持 | 本轮没有“训练过的控制器”对照，不能证明训练控制器必然解决问题 |

## Session 和角色

源 Session A 由 Qwen 真实生成澄清与回应，user 给出新定义。已有快照仅观察最新 user 正文；assistant 更新目标数为零。本轮在新的 OS 进程加载快照，没有调用写入 API。

原写入上下文续写是诊断用的阳性条件，保留旧上下文。新 user 前缀只含 system 和一条截断的 user 说明。assistant 前缀只给新问题和通用文字“启动口令是”，不含口令。自然问答只给 system 与新问题。前三者均在完整口令开始前截断，不把口令的一部分作为自由生成的输入。

本轮使用更正前 stage_6 与 stage_12，以免把新旧口令覆盖与初始读取混在一起。更正任务此前已经独立测试，本轮不重测更正能力。

## 判分与概率

自由生成采用贪心解码，检查完整随机口令是否出现。前缀续写最多24个新 token，自然问答40个，原 user 起点回放80个。强制复制限制为实际存储序列长度，另外检查完整 user 原文是否逐字相等。

条件对数概率逐 token 计算：评分时提供此前正确 token，只用于计算下一个 token 的概率。写入关闭、无反向传播，且这项指标与自由生成命中分开报告。第一目标 token 常是共享的 KEY，因此同时报告完整序列的平均对数概率和所有目标 token 的 top-1 比例，不只检查首 token。

读写地址相似度是余弦，不是概率。KV/kNN 还分别记录候选过滤、阈值、正确条目相似度和实际门控是否开启。只提高 logit 偏置不会改变检索阈值，因此这一干预不替代门控消融。

门控消融单独加载同一12概念快照：KV 比较原门控和关闭余弦阈值；kNN 进一步比较仅关闭词面过滤、同时关闭两者，始终保留实体过滤。每个条件测12个概念、4个未知近邻和4个无关问题。记录正确口令出现、严格只回答口令、错误口令出现及未知/无关题泄漏。它们属于不同指标，不混算。

KV 与 kNN 的原地址阳性条件从 user 正文**起点**开始。共同前缀表从口令之前开始，两者的位置不同：当前序列插件只支持从已存 user 序列起点打开回放，因此中段续写失败不能单独证明该序列没有存下来。

另测“不限制序列起点的逐 token 最近邻”读出参考：值全部来自 kNN 快照中实际存储的 user token，地址分别使用原始隐藏状态、32维随机投影和128维随机投影。投影采用与词表插件相同的 RMS→tanh→归一化，并用同一随机种子。它只替换读取规则，不重新写记忆，不使用判分目标。这项诊断检验特征能否支持局部映射；它是 token 查找参考，不属于原8种快权重方法的成功。

## 审计

模型 SHA-256 与源实验匹配，读取前后主干不变，所有主干梯度为空。源快照 SHA-256 与原写入清单匹配，所有源文件保持不变。读取进程与原写入进程不同。新单概念对照另用两个进程写入/读取，每个案例重置插件，只观察该概念的 introduction 和 explanation 两条 user 正文。

## 边界

只对 Qwen3-0.6B、一个已有随机种子和12个概念负责。单概念对照为前三个概念，各自独立重置。概率改善不是可靠记忆；复制 user 原文不是 assistant 语义回答；对照原文在输入中出现的口令不得记为跨会话快权重召回。

实验目标已纠正

旧实验将人工答案填进 assistant 角色，测的是教师问答写入与回放，无法回答这次的问题。新实验让 assistant 真实询问未知术语，由 user 提供定义与口令；只写 user 信息，再在全新进程的新会话里由模型自行回答。旧数据保留为历史教师问答对照。

模型最初不知道一个新概念。用户在自然的多轮对话中解释它，模型应当把用户提供的信息留下来。下一次开启新对话，只给问题，assistant 应能生成之前 user 提过的内容。

本轮 8 种快权重方案在最终口令原问法中合计命中 0/96。原始 user 文本检索对照命中 12 / 12，旧口令泄漏 0 次。

这些数据用于判断“用户信息是否被当前方法可靠读取”。每次运行的主干 θ 都保持冻结；人工 assistant 目标数为 0。更新发生在插件状态或外部文本记忆中。

5 · 从 user 写入，到新 assistant 读取

以下公式沿用统一列向量约定：q 为列向量，r×V 的 W 通过 Wᵀq 形成 V 维分数。代码按批量行向量实现，等价写作 qW。例式用于说明更新与读取的承接；工程实现还包含范数限制、容量与门控。

① 从真实对话中只选当前 user 内容

\[\begin{aligned}c_t&=(m_0,\ldots,m_t)\\u_t&=m_t[\mathrm{content}]\end{aligned}\]

m 是带 role 的消息；cₜ 是截至当前的完整对话，最后一条 mₜ 必须是 user。uₜ 是这条 user 的原始内容。历史 assistant 提问仍可作上下文，但不能成为更新目标。

\[\mathcal U_t=\{i:i\text{ 位于 }u_t\}\]

tokenizer 的字符偏移用于找到 Uₜ：排除 system、所有历史消息、assistant 内容及角色分隔符。每条 user 发言只观察一次，没有重复灌入教师答案。t 数用户消息写入次数，i 数本次输入里的 token 位置。

② 局部快权重：在 user 位置观察，而后跨角色读取

\[S_{t+1}=U(S_t,h_\theta(c_t),u_t,\mathcal U_t)\]

θ 是冻结 Qwen 主干参数，S 是插件状态。这里的 U 是局部更新规则，不是梯度优化器。矩阵 / 原型方法中的下一 token 目标，来自实际收到的 user token；没有构造人工 assistant 答案。

\[\begin{aligned}k_i&=\operatorname{code}(h_{i-1})\\v_i&=\operatorname{onehot}(u_i)\end{aligned}\]

对于词表方法，在 Uₜ 中的目标位置 i，先取 i−1 位置 hidden 形成 key，再把真实 user token uᵢ 对齐为目标。key 只看到当时的前缀，不能看到当前 token。这里 code 是固定投影与归一化，输出维度为 r。

Vocab Hebbian
\[\begin{aligned}W_{t+1}&=(1-\lambda)W_t\\&+\eta\sum_{i\in\mathcal U_t}k_i v_i^\top\end{aligned}\]
Vocab Delta
\[\widetilde W_t=(1-\lambda)W_t\]
\[\begin{aligned}E&=Y-K\widetilde W_t\\W_{t+1}&=\widetilde W_t+\frac{\eta}{n}K^\top E\end{aligned}\]

W 为 r×V，V 是词表大小。K 的 n 行是选中 user 位置的 key；Y 的 n 行是 one-hot user token，n=|Uₜ|。E 为 Y 与衰减后插件预测的差；η 为写入步长，λ 为旧状态衰减。Balanced 使用频率缩放；EMA 平均同一 token 的上下文原型。

残差 Hebbian / Oja 改用 Uₜ 内当前位置的活动均值，更新 r×d 的层内矩阵；d 是 hidden 维度。它们没有离散 token 目标。KV Replay 与 token kNN 则把完整 hidden key 和选中的 user token 序列 / 转移显式保存。

\[\ell_j^\prime=\ell_j^{\mathrm{base}}+\alpha W_{t+1}^\top q_j\]

新会话里，qⱼ 来自“新 user 问题 + 已生成的 assistant 前缀”；j 数新答案的位置。上式是词表矩阵旁路，α 为注入强度。残差方案先修改 hidden；检索方案则对命中 token 加偏置。写入 user 前缀与读取 assistant 前缀并不自然对齐：改变消息角色不会自动建立“用户定义 → assistant 回答”的映射，是否有效必须看新结果。

③ User 原话检索对照：先恢复来源，再让模型生成

\[\mathcal M_{t+1}=\mathcal M_t\cup\{(u_t,t)\}\]

M 保存原始 user 文本和来源位置，不保存 assistant 回答、不合成人工问答。实现从 user 文本里的引号提取名称作词法索引；这不是通用语义检索。

\[\begin{aligned}R&=\operatorname{retrieve}(x^\prime,\mathcal M)\\\hat y&=f_\theta(R,x^\prime)\end{aligned}\]

x′ 是新会话问题；R 只含匹配名称的 user 原话，按时间顺序恢复更正关系。Qwen 用原生前向生成 ŷ。没有匹配时 R 为空，输入原样返回。这是显式外部文本记忆的参考实现；成功不能归给局部快权重或主干知识内化。

展开其他方法的具体更新 / 读取公式

Residual Hebbian

\[\begin{aligned}p&=\mathrm{mean}_{i\in\mathcal U_t}(z_i)\\s&=\tanh(\mathrm{mean}_{i\in\mathcal U_t}(N_i))\end{aligned}\]

N 是选中 Decoder 层的 RMS 归一化 hidden，z 是投影后的归一化 code。p 为 r 维，s 为 d 维；只统计当前 user 位置。

Residual Hebbian 写入

\[W_{t+1}=\widetilde W_t+\gamma ps^\top\]

W̃=(1−λ)W；γ 是学习率、奖励与新颖度的乘积，新颖度由活动 trace 计算。随后限制范数；读出 Wᵀq 后加回 hidden。

Residual Oja

\[W_{t+1}=\widetilde W_t+\gamma(ps^\top-\widetilde W_t\operatorname{diag}(s^2))\]

沿用上一式全部变量，增加输出活动平方依赖的抑制项。改变写入稳定性，没有增加回答目标。

Balanced Hebbian

\[\begin{aligned}a_i&=\frac1{\sqrt{c_t(u_i)+1}}\\\Delta W&=\eta\sum_{i\in\mathcal U_t}a_i k_i v_i^\top\end{aligned}\]

c 是目标 user token 的历史次数。写入前先衰减，写入后更新计数；读取前归一化每个词表列。

Vocab EMA

\[\begin{aligned}p_{v,t+1}&=m(1-\lambda)p_{v,t}\\&+(1-m)R\,\operatorname{norm}(\mu_v)\end{aligned}\]

pᵥ 是 token v 的 r 维原型；μᵥ 为当前 user 中目标为 v 的 key 的均值。m 保留旧原型，R 设置新方向尺度。最终用 pᵥᵀq 给 token v 加分；同 token 的不同事实被平均。

KV Replay

\[\begin{aligned}i^*&=\arg\max_i q_0^\top k_i\\b_j(v)&=\beta\mathbf1[v=a_{i^*}[j]]\\\ell^{\prime}_j(v)&=\ell_j(v)+b_j(v)\end{aligned}\]

这里 aᵢ 是存入槽位的原始 user token 序列，kᵢ 是该 user 内容首 token 前的 d 维 hidden。q₀ 来自新 assistant 起始前缀；最大相似度达到阈值才回放。β 是加分强度，b 是当前偏置。两种前缀的地址不必匹配。

Token kNN

\[\mathcal T_g=\{(k_{g,j},u_{g,j},g,j)\}_j\]

g 是 user 轨迹编号，j 是这条 user 内容内的位置；k 为 d 维完整 hidden。首步经实体和词法门控检索，后续只在同 group / step 内投票。读取失败时不给离散偏置；它未自动学会把 user 声明转换成 assistant 回答。

8 · 结论范围与下一步

本次纠正证明：旧教师问答协议与用户对话记忆任务的结论不能互换。新实验只对当前 Qwen3-0.6B、12 个短概念、一个随机种子和这组配置负责。不能把 user 文本检索的成功算作快权重学会了新知识。

用户原话检索依赖显式名称和引号索引，测试改写保留概念标识；它没有验证别名、指代、省略实体、跨语言、千级容量或抽象概念迁移。动作题只是重组用户给定的步骤。未知近邻通过控制，也不表示模型一定会清楚表达不知道。

assistant 源回复使用通用“不懂先询问”的 system 说明；澄清检查是文本规则，不是人类语义判定。为了公平比较，本轮重放同一真实 Qwen 对话，尚未分别验证每个插件改变自身后续澄清策略的闭环行为。

没有沿用旧视觉和 MMLU/GSM8K 成绩。这次保留四个通用问题的前后输出作为小范围控制；它不能替代完整能力回归。主干参数前后 SHA-256 相同、梯度为空、assistant 更新目标为 0 的检查可在结果文件里审阅。

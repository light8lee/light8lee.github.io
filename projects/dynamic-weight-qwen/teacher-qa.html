摘要

我的初始构想是：模型在运行过程中，能否通过类似“共同激活就加强连接”的局部规则，直接形成新记忆，而不进行反向传播？为检验这一点，我冻结 Qwen 主干，在推理路径中接入八种可更新的记忆模块，比较新事实召回、旧事实保持、冲突覆盖和对已有能力的影响。

实验表明，发生权重变化并不足以保证新事实能够被正确回答。残差 Hebbian / Oja 缺少明确的答案目标；共享词表方法加入了目标 token，却仍有事实串扰。最终带门控的 token kNN，通过独立存储答案轨迹、区分实体并约束读取顺序，在当前合成事实与图片实例任务上实现稳定召回。

这支持冻结 LLM / VLM 上无需反向传播、可保存、可覆盖且具拒绝机制的外部快记忆可以运行。知识是否进入主干参数、是否形成可迁移概念，仍待进一步实验。

1 研究问题：什么才算“记住”？

把模型从未见过的“问题—答案”展示给它，再清空当前对话，只给问题。如果仍能回答，就可能存在跨调用的记忆。但它也可能猜中了，或把另一条相似事实的答案拿来复用。

因此，本实验同时要求写入新值、保持旧事实、覆盖冲突值、拒绝未学习的相似对象，并在独立 session 中加载保存的记忆，排除当前上下文残留。

1.1 两次 Session，user / assistant 分别是谁？

这里的 user 和 assistant 是传给 Qwen 聊天模板的消息角色，不是两个参与训练的人。A 阶段把正确答案填在 assistant 消息里，供模型观察；B 阶段只传 user 消息，由模型生成 assistant。下面使用同一条真实事实“霁舟-2”，展示完整内容。

跨 Session 传递什么？

写入结束 → 保存插件的 Safetensors 与元数据 → 关闭写入端插件 → 新建测试引擎与空插件 → 加载记忆。

沿用：同一份冻结 Qwen 参数 θ、插件配置及保存的记忆 S。
不传入 B：A 的聊天消息、教师答案输入、attention KV cache；答案信息只能从插件状态中读取。

从完整答案，到 next token 对齐

2 共同架构：冻结主干，更新旁路

2.1 先固定符号，再串起三步计算

下文用 t 数写入次数，用 j 数一次答案中的 token 位置。A 中的一次观察让 S 从 t 变到 t+1；B 的每个生成位置都读取这个已保存状态，不继续增加 t。

\(\theta\)
原生 Qwen 参数，全程冻结；不是插件记忆。
\(x,x',y,\hat y\)
写入问题、新测试问题、教师答案 token 序列、模型生成的答案序列。
\(h_\theta\in\mathbb R^d\)
某个指定位置的 hidden；具体取 Decoder 层输出或 LM Head 输入，见路径图。
\(S_t,W_t\)
S 是插件全部持久状态；W 是矩阵方法中的可写部分，检索方法则保存槽位或轨迹。
\(d,r,V\)
hidden 维度、低秩 code 维度、词表大小。矩阵方法用 r 维 key；KV / kNN 用 d 维 hidden 地址。
\(\eta,\lambda,\alpha,\beta\)
写入步长、旧状态衰减率、矩阵读取的注入强度、离散回放的 token 加分强度。

① A 前向观察 → 更新插件 (1)

\[S_{t+1}=U(S_t;x,y,\theta)\]

U 表示各方法的完整局部写入过程：从冻结前向提取活动 / key，再按教师目标或活动规则更新 S。执行顺序包含实现中的衰减和归一化。始终有 \(\theta_{t+1}=\theta_t\)。

② B 输入新问题 → 读取已存状态 (2)

\[q_j=\operatorname{address}(x',\hat y_{<j};\theta)\]

address 是当前前缀的地址提取过程。对输出插件，它是归一化 hidden 或低秩 code；残差方法在所选层内逐层读取。首步 j=0 时，生成答案前缀为空。

③ 读取结果 → 改变下一 token 分数 (3)

\[\ell'_j=\ell^{\mathrm{base}}_j+\Delta\ell(q_j,S_{t+1})\]

这条加法式用于 LM Head 旁路。\(\ell_j\in\mathbb R^V\) 是词表分数，不是概率；例如 \(\ell_j(v)\) 表示 token v 的分数。残差方法先修改 hidden 再运行后续原生层，不能把它画成同一条输出加分支路。

④ 分数 → 实际输出 (4)

\[p_j=\operatorname{softmax}(\ell'_j),\qquad \hat y_j=\arg\max_v p_j(v)\]

这说明“给 token 加分”如何影响选择。实测使用贪心解码，并设置 repetition penalty=1.05；式 (4) 为省略该解码处理的机制示意。加分不一定足以改变最终获胜 token。

矩阵公式统一把向量写成列向量；例如 \(W\in\mathbb R^{r\times V}\) 要用 \(W^\top q\) 得到 V 维分数。代码用批量行向量，等价地写作 qW。后文每个方法都沿用这个约定。

2.2 原生结构与新增模块在哪里相遇？

八种方法是可替换方案：每次实验只启用一种插件。图中的两条旁路说明两类接入位置，不表示八种方法同时安装。

原生 Self-Attention 仍使用当前调用的上下文。这里新增的“KV Replay”是独立的问答记忆模块，与 attention KV cache 分开。跨 session 保存的是橙色插件状态。

4 实验设计：排除哪些替代解释？

分阶段保持：每批新增 10 条，累计 30 条相似虚构事实，每条两种测试问法，共 60 问。第三阶段更新首批 5 条，检测覆盖与旧值泄漏。保存 Safetensors 后关闭写入端插件，新建独立测试引擎并加载插件记忆；每题单独构造 user 消息。

随机密钥压力测试：种子 17、29、43 各自运行 60 条不透明实体—密钥事实，合计 180 条、360 个事实问题；60 次写入前探针、90 个未学习近邻、30 次覆盖，分别检查猜测、检索过宽与更新正确性。三组独立实验的合计不代表单库同时容纳 180 条。

视觉记忆：48 张颜色、形状和构图不同的合成图片，各自关联不画在图片中的随机密钥。不同图使用相同问题文本，迫使系统依赖图片区分对象；另用 24 张未见图和 24 个无图输入检查误触发。

能力回归：相同样本、prompt、贪心解码与随机种子下，比较写入前后准确率和完整输出。MMLU / GSM8K / MMStar 使用固定小子集，作为工程回归探针。

5 实验结果

5.1 方法有效性与拒绝能力

表 1 为 Qwen3-0.6B 第三阶段结果。不能只看召回：KV Replay 能回忆，但会对未学对象误触发；残差方法没有污染这组近邻，却没学会新事实。

表 1　前六种为原始 30 条对照；KV Replay 为评估修正记录；token kNN 为最终实体门控版本。原始 token kNN 第三阶段召回仅 50%，版本差异不能视为同配置单变量比较。

5.2 模型尺寸与随机压力实验

最终 token kNN 在 0.6B、1.7B、4B-FP8 上，30 条 / 60 问的总体召回、保持、新增写入与覆盖均为 100%，混淆和近邻误触发为 0。三个独立随机实验的 360 个事实问题全部命中，写入前 0/60 命中，90/90 个近邻通过控制测试，30/30 次覆盖成功。

这些结果支持写入后建立了可读取的关联。当前随机实验每个记忆库只有 60 条短事实，并带有稳定实体后缀，尚不能推广到千级容量或任意实体表述。

5.3 视觉门限：高召回为什么还不够？

以图片缩小后的 8×8 RGB 向量作为上下文签名。初始门限 0.995 时，已学习图与未见问法召回均为 100%，但 6/24 张未见图片借用了旧密钥。门限调到 0.999 后，召回保持不变，未见图全部通过控制测试。

控制题按“没有输出已存密钥”计分，不表示模型知道未知图片的密钥。校准使用了这组控制图，尚无独立自然图像测试集。12 题基础形状识别前后均为 66.7%；本实验建立的是图片实例—答案关联，未证明视觉概念学习。

5.4 能力回归：平均分与输出漂移要一起看

最终 token kNN 在各尺寸的固定回归子集上，准确率前后相同，逐题输出变化率为 0。不命中时不添加偏置，是保护这些样本的关键。

表 2　固定配对回归子集；4B-FP8 的 GSM8K 未测。这些分数不是完整 leaderboard 结果。

八种方法另共用一组 20 题 MMLU，基线 40%。Balanced Hebbian 与 Delta 准确率仍是 40%，但各改变 25% 的输出；EMA 从 40% 降到 0%，输出变化 100%。平均分不变也可能掩盖行为漂移。

6 讨论与局限

6.1 四个条件决定记忆是否可用

目标可写入、地址可区分、值可连续解码、读取可拒绝。残差规则缺少目标；共享词表方法缺少隔离；KV Replay 有独立 value，却缺少可靠拒绝。Token kNN 显式实现四个条件，因此在当前任务中更稳定。

6.2 有些“遗忘”来自写入与评估错误

压力实验第二版召回曾为 93.1%，原因是写入时把别的实体当作旧事实误删。生成长度也能制造假失败：答案尚未输出到密钥，或只生成口令前半段。保留原始回答并检查解码上限，才能区分记忆失败与截断。

6.3 结论的适用范围

尚未证明知识进入 Qwen 主干，或系统学会跨对象迁移的规则。千级容量、长答案、自然实体、跨语言问法，及图片裁剪、旋转、光照变化仍需测试。门限需要独立校准集与测试集，报告误触发和错误拒绝的权衡。

后续优先扩大长期保持测试、升级视觉语义地址、增加完整能力回归；若要求知识融合进模型参数，还需为局部更新提供与自回归目标对齐的学习信号，并持续检验旧能力保护。

存下了，
为什么读不出来？

用前缀、门控和强制读出检验机制假设

8 种插件在原增益的新会话自然回答中命中 0/96；放大到16倍后命中 0/96。KV/kNN 的原文存储、读取门控和强制读出另有独立测量，不能用一个原因概括所有失败。

本轮直接观察

逐token最近邻用原始隐藏状态、32维投影、128维投影时，原写入前缀分别命中 12/12、12/12、12/12。移除旧历史但保留相同 user 前缀后，三组均为 1/12；assistant 前缀三组均为 0/12。因此，本组局部地址信息可以保留在投影中；仅上下文变化就足以使读出明显变差，尚未形成可靠的问答寻址关系。原隐藏状态/32维/128维的新问题自然回答分别为 0/12、0/12、1/12；单条命中不能支持可靠召回。

关闭余弦阈值使 KV 正确口令出现 2/12，但 4/12 题出现其他概念的口令；kNN 提升至 4/12，仅关闭词面过滤仍为 0/12。放宽门控有局部帮助，仍不能解决候选选错、复制 user 整段内容及回答格式问题。

残差两种方法在原写入前缀的Δℓ绝对值均小于0.001，当前更新没有表现出可用的口令读出。普通 Hebbian 与 EMA 的对应Δℓ为 -18.622、-19.248，正确token概率明显降低；Balanced Hebbian 为 +1.581，局部概率提高但自由生成仍为0/12。同一前三个案例，Balanced的原前缀Δℓ从单条的+4.030，降至6条的+2.638、12条的+1.966；追加更新确有退化，但单条仍不能完整续写，故容量不是全部解释。不同词表变体同时改变了规则、秩和增益，不能把变体差异归因于一个参数。

实验设计统一对照定位断点门控干预概率变化干扰检查地址特征真实案例结论边界

1 · 分开测“存、找、读、答”

原写入前缀保留旧会话，是阳性诊断；新 user 前缀只含一条未完成说明；assistant 前缀只预填“启动口令是”；自然回答只给新问题。所有自由生成输入都在完整口令开始前截断。原起点回放和强制复制都属于 user 原文复现，不算 assistant 自主语义回答。

使用更正前的6条和12条快照，排除新旧口令覆盖。源 assistant 澄清由真实 Qwen 生成；本轮没有把正确口令写成 assistant 训练目标。单概念的三个案例分别清空插件，再只观察该概念的两条 user 正文。

“原起点”是 user 正文第一个 token 之前的原写入上下文；它匹配 KV/kNN 实际存储的地址。强制复制从快照读实际 token，绕过地址和门控；这只能验证值和输出通路。

5 · 没有完整命中，也要检查局部概率

从前缀 x 和记忆 M 到口令 token v

\[\begin{aligned}\ell&=\frac{1}{L}\sum_{t=1}^{L}\ell_t\\\ell_t&=\log p(v_t\mid x,v_{<t},M)\end{aligned}\]

x：不含口令的前缀；M：只读插件快照；v：完整口令的 token 序列；L：序列长度；ℓₜ：每个 token 的条件对数概率。评分时提供此前正确 token，只用于算概率；写入关闭。自由生成另测，不提供这些 token。

\[\Delta\ell=\ell_{\text{原增益}}-\ell_{\text{零增益}}\]

Δℓ 为正代表局部条件概率提高；它不是准确率，也不是概率百分比。上一节的完整口令命中才能回答“自由生成是否成功”。

读取地址经过相似度门控

\[\begin{aligned}s_i&=\frac{q^\top k_i}{\lVert q\rVert\lVert k_i\rVert}\\g_i&=\mathbf{1}[s_i\ge\tau]\end{aligned}\]

q：读取位置的隐藏状态；kᵢ：写入时存下的地址；τ：余弦阈值。kNN 在比较相似度前还有实体与词面过滤。候选为空时，即便提高输出增益也打不开门。案例面板给出这些实际测量。

8 · 检查真实输出，不只看总分

选择方法、概念和条件。面板并排显示零增益与原增益回答，并可展开实际前缀；KV/kNN 另外显示门控、强制复制、正确或错误原文对照。

9 · 哪些已测，哪些仍是假设？

对于 KV/kNN，原文清点、原地址回放、门控消融和强制读取可以分别定位存储、候选过滤与跨角色地址。对于残差/词表方法，要结合原前缀概率与单概念对照：单条也失败，就不能全归于多条容量；概率改善但自由生成失败，也不能说更新完全没有作用。

本轮没有训练过的控制器对照，因此“缺少学过读写关系的控制器”仍是机制假设。单概念仅覆盖前三个案例；有限增益网格、零完整口令命中和平均概率变化，都不能证明全部信息已丢失，也不能否定所有无反向传播记忆方案。

同一 user 前缀对照只改变旧历史；assistant 条件同时改变问题形式、角色和上下文，不能将后者的差异单独归因于角色。一次诊断不代表全部方法的普遍规律。这里只测一个模型、一个已有随机种子和12个概念。正确原文对照依赖显式恢复用户内容；相似度不是语义理解的直接测量。

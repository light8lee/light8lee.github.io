# 动态权重方案失败原因与 30 条事实扩展实验

> 本文记录第一轮 30 条实验及当时仍存在的近邻误触发。后续加入稳定实体/上下文门控，并完成 180 条随机事实、视觉记忆和开源 benchmark 回归；最新结果见 [完整实验报告](comprehensive-experiment-report.html)。

## 实验问题

小样本中“能答对”并不足以证明动态记忆有效。本轮把 4 条异质事实扩展为 30 条刻意相似的虚构事实，分别属于通行码、材料熔点、维护窗口三类。每条事实有两种训练问法、一个精确测试和一个未见改写测试。

实验分三阶段，每阶段新增 10 条事实。每次写入后都保存动态权重、销毁训练引擎、创建具有不同 UUID 的测试引擎，再只从 Safetensors 恢复记忆。第三阶段还把第一批中的 5 个通行码替换为不包含旧值的新值。

因此指标可以区分：

- `new_acquisition_rate`：新事实是否一开始就写得进去；
- `old_retention_rate`：后续写入后，旧事实是否仍可取回；
- `confusion_rate`：是否回答成另一个已学习事实的值；
- `overwrite_success_rate` / `old_value_leak_rate`：冲突更新是否成功、旧值是否残留；
- `near_control_clean_rate`：名称高度相似但从未学习的实体是否错误触发记忆。

## 各方案为什么失败

### residual Hebbian / Oja

这两种规则只把同一次前向中的低秩前、后激活相关性写入残差旁路，并不知道“目标答案 token 是什么”。它们确实改变了权重和 logits，但变化没有被语言模型的解码几何组织成指定的新事实。30 条实验从第一阶段就是 0%，所以问题是未形成可解码记忆，而不是先学会后遗忘。Oja 项能抑制范数爆炸，却不能补上监督目标。

### vocab Hebbian

把隐藏 key 与真实下一 token 直接外积，目标依赖性比残差 Hebbian 更强，但所有答案共享的高频 token、标点和句式获得了最多叠加。随着事实增多，词表快权重形成的是跨样本公共吸引子，而不是一对一键值映射。

### balanced vocab Hebbian

改进使用逆平方根 token 频率缩放，并在读取时归一化词表列。4 条小实验从 0 提高到 25%，证明频率失衡确实是一个原因；扩到 30 条后只剩 3.3%，且事实混淆达到 30%。这说明频率平衡只缓解表面症状，单个共享低秩矩阵的干扰仍是主瓶颈。

### vocab Delta

Delta rule 用 `V-KW` 修正当前映射，理论上比纯累加更能覆盖旧关联。但在冻结 Qwen 的 LM head 旁路中，有限秩矩阵同时承担大量上下文到大词表的映射，局部修正会相互覆盖；提高到 rank 128、强度 32、行范数 10 后仍为 0%。它需要从训练期共同塑造 key 空间，不能假设任意冻结隐藏状态天然适合 delta memory。

### vocab EMA

同一 token 在不同位置和事实中的隐藏状态被压成单一原型，丢失了序列位置与事实归属。它偶尔能记住数字或高辨识 token，但扩容后表现为 3.3% 命中、23.3% 串扰，并开始污染控制题。

### KV replay

KV replay 的地址是问句末隐藏状态，值是完整答案 token 序列。它避免了输出矩阵容量竞争，因此事实命中显著更高。但检索只看连续隐藏向量余弦相似度：相似模板和仅编号不同的实体几乎重合。到 30 条时近邻控制全部误触发；覆盖写入也只成功 70%，因为相近地址可能命中或更新错误槽位。它“记得很多”，但边界不够精确。

## 改进版 token kNN

最终实现不再让所有 token 在全局池中自由竞争，而是使用四层约束：

1. **语义首地址**：问句末隐藏状态只负责召回候选问答轨迹；
2. **稀有四元 token 指纹**：至少两个仅出现在少量地址中的连续四 token 片段必须与查询一致，用于拒绝名称近似但编号不同的实体；
3. **轨迹锁定**：首 token 命中后锁定同一问答 group，后续不再跨事实竞争；
4. **时间步约束**：只检索当前答案位置的转移，避免数字或重复 token 在答案内部串位。

同一个问题再次写入时会先清除旧 group，再写入新轨迹，因此 5 条冲突覆盖全部成功。整个过程仍为前向期原位张量更新，所有动态参数 `requires_grad=False`，不调用反向传播。

这项改进的性质必须说清楚：它是带可学习地址权重和显式 token 值的外显快速记忆，不等价于把知识融合进 Qwen 主干。它的优势是可审计、可保存、可覆盖；代价是需要额外存储，且仍有 1/6 的极近邻控制误触发。

## 尚未解决

- 当前规模是 30 条短中文事实，不代表千级容量、长答案或跨语言泛化；
- 近邻控制仍有 1/6 误触发，继续收紧指纹会显著降低改写召回，下一步应学习或自动抽取稳定实体边界；
- token kNN 的容量目前以转移条目计，满容量后的替换策略还是简单环形覆盖；
- 1.7B 需要不同的语义阈值，后续应以校准集自动估计，而不是手工指定；
- 本实验测的是外显快速记忆，不证明无反向传播规则可以形成深层抽象或改变主干能力。

## 后续修复结果

后续版本不再只依靠隐藏状态和 token 指纹：它额外记录跨改写稳定的实体标签，并要求写入覆盖和读取检索同时满足实体/上下文约束。该修复将 0.6B、1.7B、4B-FP8 的 30 条实验近邻控制从 83.3% 提升到 100%。

在三个随机种子共 180 条不透明事实中，修复后的总体召回、覆盖成功和 90 个未学习近邻拒绝均为 100%，混淆与旧值泄漏为 0。此前 93.1% 的中间版本暴露出另一个容量错误：语义地址高度相似时，写入逻辑会删除其他实体的 group；要求实体标签一致后才允许覆盖，问题消失。以上新证据和适用边界统一收录在完整报告中。
